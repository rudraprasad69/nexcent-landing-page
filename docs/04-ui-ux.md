# Nexcent Landing Page
## UI/UX Design Brief and Visual Language

## 1. Design direction
The page uses contemporary SaaS editorial design: generous white space, clear typography, restrained pale-gray bands, dark slate text, fresh green actions, and illustrative storytelling. The visual tone should feel trustworthy, calm, and practical rather than overly decorative.

## 2. Reference structure
The supplied reference is a narrow mobile capture of the Figma landing page. It shows a white navigation bar, pale hero panel, green-highlighted hero copy, illustration, client logo row, three audience cards, alternating feature sections, a metrics band, testimonial panel, article cards, CTA, and dark footer.

## 3. Color tokens
- **Nexcent green:** `#4CAF50` for actions and highlights.
- **Green hover:** `#388E3C` for interaction feedback.
- **Dark slate:** `#263238` for headings and footer.
- **Pale gray:** `#F5F7FA` for hero, metrics, and CTA bands.
- **Muted gray:** `#6B7280` for supporting copy.

## 4. Typography
Use a clean sans-serif system with strong weight contrast. Headings are compact, bold, and high contrast; body copy is smaller with relaxed line-height. Important headings should use balanced wrapping, and no text should be reduced below a readable mobile size.

## 5. Layout
Use a centered container with generous gutters. Flexbox is the default layout method; grid is reserved for the metrics, feature cards, and article cards. Feature splits alternate image and copy on desktop and stack naturally on mobile. Cards use soft corners, subtle borders, and restrained shadows rather than decorative accent stripes.

## 6. Responsive rules
At mobile widths, the nav collapses, two-column areas stack, buttons become easier to tap, and card grids become one column. At tablet widths, gutters reduce while visual hierarchy remains unchanged. Desktop preserves the wide composition and generous section rhythm.

## 7. Accessibility
Maintain meaningful contrast, clear focus rings, semantic landmarks, descriptive image alternatives, and touch targets suitable for mobile. Do not use icons as the only means of communicating an action.

## 8. Fidelity checklist
Match section order, hero proportions, green emphasis, illustration placement, logo density, card spacing, metric alignment, footer hierarchy, and the visual rhythm seen in the reference. Remove decorative elements that do not support the product story.
